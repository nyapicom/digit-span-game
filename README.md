# 逆順復唱ゲーム

## 概要

短期記憶を鍛えるためのゲーム。
画面にいくつかの数字が順に表示され、逆順にタイピングすると成功となるゲーム。
HP制で、失敗するとHPが1減り、HPが0以下になるとゲームオーバー。
成功すると一定時間後に自動で次のラウンドへ移行する。
失敗してもHPが残っている場合は難易度を少し緩めた状態で自動的に同じラウンドへ再挑戦し、そこで成功すれば元の桁数に戻ったうえで次へ進む。
数字が表示されるたびに短い効果音を鳴らし、同じ数字が続いても識別しやすくする。
成功するにつれて難易度が徐々に上がっていく（数字の数が増え、表示時間も短くなる）。

タイトル画面で難易度（初期の数字個数、初期HP）を選択できる。

## 実装

Webアプリとして実装
- Next.js, TypeScript, biome, Tailwindcss, pnpm
