# 数字復唱ゲーム（digit-span-game）

## 概要

短期記憶を鍛えるためのゲーム。いくつか数字が画面に表示される。同じ順番、または逆順にタイピングするゲーム。

## 詳細

HP制で、プレイヤーは最初HPを3持っている。回答が間違っていた場合、HPが1減り、HPが0以下になるとゲームオーバー。

何回か連続で成功すると、難易度が1段上がる（表示される数字の数が1つ増える）。

逆に、失敗すると、即座に難易度が1段下がる。

成功・失敗表示後は、一定時間後に次のラウンドに進む。

数字が表示されるたびに短い効果音を鳴らし、同じ数字が続いても識別しやすくする。

タイトル画面で初期難易度（数字個数）をスライドバーで選択できる。選択はクッキーに保存しておく。

## 実装

Webアプリとして実装
- Next.js, TypeScript, biome, Tailwindcss
- pnpm

## コマンド

- インストール `pnpm i`
- 立ち上げ `pnpm dev`
